# 主城入口示範 · city-portals-1

本輪是可操作的介面原型，所有人物、案件、排行與資源均為本機固定示範資料。操作效果預覽不修改人物、庫存、國庫、年份或其他遊戲狀態。不連接 GAS、雲端存檔、排行榜或 GPT API。

## 入口與操作

| 建築 | 分頁／內容 | 固定捷徑 |
| --- | --- | --- |
| 太和殿 | 上朝、待決事件、本年摘要 | 朝廷 |
| 六部衙門 | 任命、官員、科舉、稅政、改革、外交 | 官員、國政 |
| 軍機處 | 貪官密查、調查進度及案件詳情 | 從建築進入 |
| 兵營 | 募兵／遣散、出征、邊疆部署 | 軍事 |
| 後宮 | 妃嬪資料、探望、深宮秘聞、案件 | 後宮 |
| 上書房 | 皇嗣教育、入學、皇家書院 | 從建築進入 |
| 御書房 | 文武培養 | 皇帝資料亦可進入 |
| 宗人府 | 族譜關係清單、歷代皇帝、宗室婚配 | 從建築進入 |
| 皇家寶庫 | 補給、珍玩、使用與賞賜 | 寶庫 |
| 宮門 | 微服私訪、省份與建設詳情 | 疆域 |

太和殿與宮門名稱是主城導覽用途，並非精確宮廷制度或建築測繪復原。

- 一般模式點建築高亮並開啟面板。拖建築或空地均平移鏡頭；拖移超過門檻不開面板。
- 底部捷徑使用與建築相同的入口資料，官員預選任命分頁，國政預選稅政分頁，疆域預選省份分頁。
- 面板卡片可打開詳情；有操作的項目可顯示預覽結果。任命、稅率、部署、教育、探望、外交及道具提供示範選項，預覽摘要保留所選內容。
- 返回依「來源面板 → 詳情 → 操作預覽」逐層返回。關閉或 Escape 返回主城，鏡頭位置維持不變。
- 電腦面板位於右側；手機預設底部 74dvh 面板，點詳情自動展開至全螢幕，也可手動展開／收合。面板打開時用原生 dialog 管理焦點並隔離背景操作。
- 左側待辦可進入朝廷、官員、防守與后宮事件。範例待辦不會因預覽操作消失。
- 右下結束本年顯示待處理事項及年度結算示例，不推進年份。
- 皇帝頭像提供資料、成就及虛構排行榜；頂部資源可查看說明。
- 設定內的日夜、動畫、重置鏡頭及配置模式會作用於實際場景。音訊按鈕開啟時試聽一次 Web Audio 合成宮鐘，關閉時靜音；不是背景音樂。
- 存檔頁只說明本機配置與未連接的正式存檔；不提供假成功的上傳／下載操作。
- 起居注可展開查看固定示範記錄。

## 建築配置與資料隔離

十座建築都能在配置模式直接拖移；標籤、輪廓命中與深度排序同步移動。配置模式隱藏政務待辦、起居注與底部捷徑以騰出操作空間，點建築不打開面板。

新地圖 2600 × 1800，使用 `dachikingdom:pixi-palace:city-layout:v1`；資料 `version: 1`、`scene: city-portals-1`。舊版三建築配置鍵 `dachikingdom:pixi-palace:building-layout:v1` 保留原樣，不遷移、不讀寫。還原只刪除新地圖配置。所有位置資料只存在同源瀏覽器，不涉及正式存檔。瀏覽器拒絕儲存時可在記憶體中編輯並顯示提示。

## 實作與範圍

- `src/portal-data.ts`：固定示範資料、入口對照、預覽選項與面板導航狀態。
- `src/portals.ts`：原生 DOM 面板及操作，不引入 UI 框架。
- `src/main.ts`：PixiJS 場景、手勢、點建築開啟面板。
- `src/layout.json`：十座建築與場景位置，供 PixiJS 和靜態排版共用。

本次沒有製作戰鬥、經濟、抽卡、教育成長或后宮事件模擬；族譜以關係清單呈現。人物使用文字資料卡，沒有新增人物肖像。巡邏路線仍固定，拖建築後不避障。夜景沿用整體色調與燈光，不另載夜間建築圖。

## 更新與驗證

本次更新僅在 `experiment/pixi-palace-art-test` 的獨立目錄，正式版本號保持不變。新增七張建築 WebP，由兩張新來源圖裁切／編碼，共十九張 WebP。具體容量與測試結果見 PERFORMANCE.md。

所有瀏覽器／手機交互、焦點、遮擋及響應式版面仍須實機驗收；自動測試不等同瀏覽器測試。預覽基礎設施轉送逾時，尚未取得實際 FPS。
