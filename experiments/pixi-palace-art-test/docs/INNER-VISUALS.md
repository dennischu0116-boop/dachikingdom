# 內頁視覺更新 · inner-visuals-1

本輪將主城所有十五個功能入口、三十五個分頁及其詳情，改為與宮廷主城相協調的全螢幕內頁。深墨綠、朱紅、舊金邊框搭配生成的宮廷背景、透明人物肖像與器物。文字、按鈕、人物與背景分開呈現，沒有把完整概念圖當成互動介面。

這是獨立測試專案的視覺與操作原型。正式遊戲的三個中央官職為丞相、戶部尚書、兵部尚書；此處對照目前功能組織畫面，沒有匯入正式遊戲執行邏輯。人物、數值、案件、疆界與排行榜仍為虛構示例。

## 可操作的示範

- 官員姓名搜尋、類型／任職篩選、能力排序、勾選與批次操作預覽。搜尋支援中文組字完成後更新；實際輸入法操作仍待瀏覽器驗證。
- 各官員課程選取、安排總覽。課程與篩選只保留在本次頁面記憶體，重新整理重設。
- 科舉單抽／十連顯示一或十張固定示範名帖，使用三種候選肖像；不隨機抽取、不改保底、不消耗資源。
- 任命、教育、部署、探望、外交、道具等仍沿用詳情選項與效果預覽。
- 系統頁的晝夜、動畫、鏡頭、配置模式連到原場景控制；其餘人物／資源操作不寫入正式資料。
- 返回逐層退回來源，返回主城保留鏡頭。十座建築已保存的位置及儲存格式保持相容。

## 預覽與重建

互動版執行 `npm ci`、`npm run dev`，開啟終端網址，可直接加以下 query：

- `/?page=ministries&tab=officials`
- `/?page=ministries&tab=roster`
- `/?page=harem&tab=consorts`
- `/?page=military&tab=defense`

全部分頁的實際 HTML／CSS 靜態匯出見 [預覽目錄](inner-pages/index.html)。保留專案目錄結構即可雙擊此目錄頁；按鈕不具互動。`npm run previews:ui` 可重建全部靜態頁及以下三張圖：

- [官員桌面設計圖](officials-visual-desktop.png)
- [官員手機設計圖](officials-visual-mobile.png)
- [四類內頁設計總覽](inner-visual-overview.png)

PNG 是使用實際 WebP 的 SVG／Sharp 美術排版示意，並非網站 HTML 的截圖；實際版面文字、尺寸和操作以執行網站為準。不能用設計圖代替 CSS 或瀏覽器驗收。

## 限制

本輪未連接正式存檔／後端，也未實作經濟、戰鬥、隨機招募或年度成長。素材是美術詮釋，未作歷史考據；疆域圖為示意，公主在族譜中以名牒呈現。背景使用四種宮廷環境，部分檔案共用器物，不是每個事件均有獨立插畫。全螢幕功能頁是 HTML／CSS，主城仍由 PixiJS 渲染；人物沒有骨骼動畫。

瀏覽器預覽服務因 relay 逾時而無法啟動，尚未驗證實際響應式布局、觸控、dialog 焦點、圖片載入及 FPS。詳見 PERFORMANCE.md。只修改 experiment 分支的本目錄，不更改正式版本號、main、GAS 部署、人物圖片服務或正式存檔。
